# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Reporting Bugs and Sharing Ideas

Open an issue in this repository to report a bug, suggest an enhancement, or share
an idea. For bug reports, include the steps to reproduce the problem, the expected
result, and the actual result.

## Submitting Changes

1. Fork the repository and create a branch for your changes.
2. Make your changes and check that the documentation, formulas, and examples are accurate.
3. Commit your changes with a clear message.
4. Open a pull request against the `main` branch of this repository.
5. Explain what you changed and link to any related issue.

Keep discussions respectful and constructive. Thank you for helping improve the
Simple Interest Calculator project!
